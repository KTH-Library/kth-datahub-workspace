# Översikt digitala verktyg

En översikt över digitala tjänster som forskare vid KTH kan använda för att
lagra, beräkna, dela och publicera forskningsmaterial. Sök fritt, filtrera på
leverantör, funktionsgrupp eller tjänstetyp, eller klicka på en tagg för att se
allt som matchar. Välj en tjänst för att öppna tjänstekortet med åtkomst,
guider och mer information.

Uppgifter som saknas markeras som *uppgift saknas* i stället för att utelämnas.
Kostnad beskrivs i förhållande till andra alternativ i stället för som en
prislista, och risker beskrivs på samma sätt för alla leverantörer.
