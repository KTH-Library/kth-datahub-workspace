    Översikt digitala verktyg

    En översikt över digitala tjänster som forskare vid KTH kan använda för att lagra, beräkna, dela och publicera forskningsmaterial. Sök fritt, filtrera på leverantör, funktionsgrupp eller tjänstetyp, eller klicka på en tagg för att se allt som matchar. Välj en tjänst för att öppna tjänstekortet med åtkomst, guider och mer information.

    Uppgifter som saknas markeras som uppgift saknas i stället för att utelämnas. Kostnad beskrivs i förhållande till andra alternativ i stället för som en prislista, och risker beskrivs på samma sätt för alla leverantörer.

    Inga tjänster matchar filtret.

    Zenodo

    CERN / EU

    Allmänt repositorium för att publicera datamängder, programvara och annat forskningsresultat med DOI.

    Åtkomst

    Inget avtal och ingen ansökan krävs. Upp till 50 GB per post är kostnadsfritt, större datamängder kan begäras.

    Guider
    1. Logga in på https://zenodo.org med ORCID så kopplas publiceringen till dig.
    2. Välj New upload, lägg till filer och fyll i titel, författare och licens.
    3. Reservera en DOI om du behöver referera till datamängden innan publicering.
    4. Publicera — posten och DOI:n blir permanenta.
    Om tjänsten

    Zenodo stödjer FAIR-publicering med beständiga identifierare, öppna licenser, versionshantering och maskinläsbara metadata. Poster kan embargoläggas eller begränsas, men Zenodo är inte avsett för personuppgifter eller konfidentiella data.

    Om tjänsten Till tjänsten

    Dropbox

    Dropbox Inc.

    Kommersiell fildelning som är vanlig i externa samarbeten men saknar centralt KTH-avtal.

    Åtkomst

    Det finns inget centralt KTH-avtal, så kostnaden bärs av projektet eller individen. Jämfört med KTH OneDrive, som redan är centralt betald, innebär Dropbox en direkt kostnad.

    Guider
    1. Skapa eller gå med i ett Dropbox-team som ägs av projektet.
    2. Sätt upp en delad projektmapp med namngivna medlemmar i stället för öppna länkar.
    3. Gå igenom delningsinställningarna regelbundet och ta bort medlemmar som slutar.
    Om tjänsten

    Dropbox används brett av externa parter, vilket kan göra det praktiskt i samarbeten. Lagringsplatsen är global och inget personuppgiftsbiträdesavtal finns med KTH, så tjänsten bör inte användas för personuppgifter eller konfidentiella data.

    Om tjänsten Till tjänsten

    EOSC EU Node lagring

    EOSC

    Lagring och beräkning i European Open Science Cloud, inklusive Jupyter-notebooks nära data.

    Åtkomst

    Logga in med din lärosätesidentitet (KTH) i EOSC EU Node-portalen. En grundtilldelning är kostnadsfri, större tilldelningar begärs i portalen — uppgift saknas om aktuella kvotgränser.

    Guider
    1. Öppna EOSC EU Node-portalen och logga in med ditt KTH-konto.
    2. Välj File sync and share för lagring eller Interactive notebooks för Jupyter.
    3. Ladda upp eller montera projektets data.
    4. Dela mappar med projektmedlemmar via deras EOSC-identiteter.
    Om tjänsten

    Data stannar inom EU-infrastruktur, vilket underlättar krav från finansiärer och regelverk om lagringsplats. Tjänsten utvecklas snabbt, så tillgänglighet och kvoter kan ändras under ett projekts livslängd.

    Om tjänsten Till tjänsten (kräver inloggning)

    KTH OneDrive

    KTH

    Personlig och delad molnlagring som ingår i KTH:s Microsoft 365-avtal, lämplig för löpande arbetsmaterial.

    Åtkomst

    Logga in med ditt KTH-konto. Ingen ansökan och ingen extra kostnad för den enskilda forskaren, eftersom tjänsten ingår i det centrala avtalet.

    Guider
    1. Gå till https://portal.office.com och logga in med ditt KTH-konto.
    2. Välj OneDrive i appväljaren.
    3. Skapa en projektmapp och använd Dela för att bjuda in kollegor med KTH-adress.
    4. Installera skrivbordsklienten om du vill synka mappen lokalt.
    Om tjänsten

    OneDrive är avsett för arbetsmaterial under projektets gång, inte för arkivering. Data som ska bevaras eller publiceras flyttas till ett repositorium när projektet avslutas. Känsliga personuppgifter kräver en separat bedömning — uppgift saknas om godkända kategorier för just ditt projekt innan en dataskyddsgranskning är gjord.

    Om tjänsten Till tjänsten

    GitHub

    Microsoft

    Versionshantering och samarbete kring kod, analysskript och dokumentation, med KTH-organisationer tillgängliga.

    Åtkomst

    Skapa ett personligt konto och be ägaren till aktuell KTH-organisation lägga till dig. Privata repositorier ingår utan kostnad för akademisk användning.

    Guider
    1. Skapa ett repositorium och lägg till README.md och en licensfil.
    2. Klona lokalt med git clone och committa arbetet regelbundet.
    3. Använd brancher och pull requests när flera arbetar parallellt.
    4. Koppla repositoriet till Zenodo för att få DOI vid varje release.
    Om tjänsten

    GitHub passar för kod och textbaserat material. Det ska inte användas för personuppgifter eller stora binära datamängder. Data lagras globalt, vilket måste vägas in när projektet har krav på lagringsplats.
