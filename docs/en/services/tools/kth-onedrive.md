## Access

Log in with your KTH account. No application or extra cost for the individual
researcher; the service is part of the central agreement.

## Guides

1. Open <https://portal.office.com> and sign in with your KTH account.
2. Choose **OneDrive** in the app launcher.
3. Create a project folder and use **Share** to invite co-workers by KTH e-mail.
4. Install the desktop client if you want the folder synced locally.

## About the service

OneDrive is intended for working material during a project. It is not an
archive: data that must be preserved or published should be moved to a
repository at the end of the project. Sensitive personal data requires a
separate assessment before use — uppgift saknas about approved categories for
your specific project until a data protection review is done.
