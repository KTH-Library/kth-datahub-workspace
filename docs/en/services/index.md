# Digital services overview

An overview of digital services that researchers at KTH can use for storing,
computing on, sharing and publishing research material. Search freely, filter by
provider, function group or service type, or click any tag to see everything
that matches it. Select a service to open its card with access details, guides
and further information.

Missing information is marked as *uppgift saknas* rather than left out. Costs
are described in relation to other options instead of as a price list, and risks
are described the same way for all providers.

!!! info "Add a service"

    Adding a file there is enough — the card, tags, filters and the service page
    are generated automatically.
