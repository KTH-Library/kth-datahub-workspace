## Access

Sign in using your institutional account. No application process or additional
cost is required for individual users because the service is included within
the central service portfolio.

## Guides

1. Open the service portal and sign in with your institutional account.
2. Access the storage application from the service launcher.
3. Create a project folder and share it with collaborators using institutional e-mail addresses.
4. Install the desktop synchronisation client if local file synchronisation is required.

## About the Service

The service is intended for working material used during projects and day-to-day
activities. It is not intended to replace dedicated archiving or long-term
preservation solutions. Data requiring additional protection measures may need
a separate review before use, depending on project requirements and applicable
regulations.
